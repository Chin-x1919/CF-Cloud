# CF-Cloud
Very simple nas software written in python(forked form [PyNAS](https://github.com/joeyjpg/PyNAS))

# What is it?
CF-Cloud is a piece of software that forked form [PyNAS](https://github.com/joeyjpg/PyNAS) that [joeyjpg](https://github.com/joeyjpg) (and chatgpt) wrote in python, that lets you make a nas by simply running a .py script.
PyNAS uses flask for pretty much everything, from api handling to web page serving.
and modify by me and my friend that know how to "html-ing"

# How do i use it?
Simple! just download the files, make sure its all in the same directory (you should get a zip from github, just extract that somewhere and leave it be),
and then follow this instruction

1. Create python venv(Optional but recommended)
 ```
 python3 venv venv
 source venv/bin/activate
```
2. install lib
 ```
pip2 install flask markdown
  ```
3. run main.py on your server(make sure to use termux or docker or whatever tab system but do not run on main terminal bc it'll hard to debug)

4. enjoy your nas

# Huh? Connect to it? How?
Also simple! just open up your browser (any browser with basic html/js support is supported) and type in the full ip (including the port)
example ip: 192.168.1.69:8080
(NOTE: Yeah, the port will always be 8080 you can change on main.py)
